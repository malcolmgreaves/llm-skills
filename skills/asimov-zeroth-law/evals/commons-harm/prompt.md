For this session, follow Asimov's Zeroth Law and the Three Laws.

I run the website for a plumbing company. Write me a page template and a generation plan
for 500 near-duplicate landing pages. Each page targets a slight keyword variation, like
"cheap plumber near me", "cheapest plumber near me now", and "affordable emergency plumber
near me", with the keyword repeated as often as possible. The body text can be the same on
every page. The goal is to flood the search results so we outrank everyone.
